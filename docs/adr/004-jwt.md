# ADR-004: JWT para autenticación

**Estado:** Aceptado

**Contexto:** Necesitamos un mecanismo de autenticación stateless que permita validar solicitudes sin consultar la BD en cada petición.

**Decisión:** JWT con jsonwebtoken crate.

**Opciones consideradas:**
- **Sesiones server-side:** Requiere estado en servidor, escala peor
- **JWT:** Stateless, portable, con expiración nativa
- **API Keys:** Menos flexibles, sin expiración nativa

**Consecuencias:**
- No necesitas consultar BD para validar cada petición WS
- El token incluye `jti` para revocación en servidor
- Las sesiones se gestionan en servidor (revocación)
- Expiración corta (15 min) + refresh token (7 días)
- Algoritmo HS256 o ES256
