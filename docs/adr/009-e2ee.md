# ADR-009: Cifrado extremo a extremo (E2EE)

**Estado:** Aceptado

**Contexto:** Los mensajes nunca deben ser legibles por el servidor ni por terceros. Solo el remitente y el destinatario pueden leerlos.

**Decisión:** XChaCha20-Poly1305 + X25519 ECDH + Ed25519 firmas.

**Opciones consideradas:**
- **AES-256-GCM:** Soportado en hardware, pero XChaCoCha20 es más seguro con nonces largos
- **XChaCha20-Poly1305:** Nonce de 192 bits (sin riesgo de colisión), más rápido en software
- **Age:** Abstracción de alto nivel, menos control

**Consecuencias:**
- Intercambio de claves vía X25519 (ECDH)
- Cifrado simétrico con XChaCha20-Poly1305
- Firmas Ed25519 para autenticación del remitente
- Perfect Forward Secrecy vía claves efímeras (Doble Rachet)
- Claves almacenadas en keychain del SO
- Sin respaldo de claves (responsabilidad del usuario)
